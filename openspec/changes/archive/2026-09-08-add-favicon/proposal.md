## Why

The application has no favicon to identify its browser tab.

## What Changes

- Add a local card-themed favicon using the application colors.
- Reference it from the shared HTML document so room URLs use it too.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `app-delivery`: Serve and reference an application favicon from the same origin.

## Impact

Frontend HTML and one SVG asset. No new dependencies or backend changes.
